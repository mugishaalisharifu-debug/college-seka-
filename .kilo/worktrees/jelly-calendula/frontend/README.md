# 👥 User Roles & Responsibilities

---

# 🔑 System Administrator

## Description

The **System Administrator** is the highest-level user of the College Foundation Sina Gerard (CFSG) School Management System. This user has complete control over the entire system and is responsible for managing users, configuring the system, monitoring all activities, and ensuring the smooth operation of the platform.

## Responsibilities

- [ ] Login to the system
- [ ] View the Administrator Dashboard
- [ ] Configure school information
- [ ] Configure academic years
- [ ] Configure school terms
- [ ] Publish announcements
- [ ] Manage gallery
- [ ] Upload downloadable documents
- [ ] Generate all reports
- [ ] Export reports

---

# 🎓 Headmaster

## Description

The Headmaster supervises the daily academic and administrative activities of the school. The Headmaster reviews admission applications, approves qualified students, assigns students to classes, and oversees teachers and school operations.

## Responsibilities

- [ ] Login to the system
- [ ] View Headmaster Dashboard- [ ] View enrolled students
- [ ] View all reports
- [ ] View school reports
- [ ] Export reports

---

# 🗂 Administrative Staff

## Description

Administrative Staff verify applications before they reach the Headmaster. They ensure that every application contains the required information and documents before forwarding it for approval.

## Responsibilities

- [ ] Login to the system
- [ ] View new applications
- [ ] Verify application information
- [ ] Verify uploaded documents
- [ ] Update applicant information
- [ ] Forward verified applications
- [ ] Manage parent information

---

# 🏫 School Reception Officer

## Description

The School Reception Officer welcomes students after they have been approved by the Headmaster. Only approved students appear in this module. The officer verifies that students have submitted every required document, school item, boarding material, and TVET equipment before registration is completed.

## Responsibilities

- [ ] Login to the system
- [ ] View approved students only
- [ ] Search student by name or admission number
- [ ] Open student profile
- [ ] Verify birth certificate
- [ ] Verify previous school report
- [ ] Verify passport photos
- [ ] Verify medical report
- [ ] Verify school uniform
- [ ] Verify sports uniform
- [ ] Verify boarding requirements
- [ ] Verify TVET practical equipment
- [ ] Mark requirement as **Received**
- [ ] Mark requirement as **Not Received**
- [ ] Add remarks for missing items
- [ ] Update requirement status
- [ ] Print requirement checklist
- [ ] Generate requirement reports

---

# 📋 Complete Admission Workflow

- [ ] Student submits online application.
- [ ] Administrative Staff verify the application.
- [ ] Headmaster reviews the verified application.
- [ ] Headmaster approves or rejects the application.
- [ ] If approved, the student is assigned to a class.
- [ ] The approved student appears in the Reception Officer dashboard.
- [ ] Reception Officer verifies all required documents and school materials.
- [ ] Missing requirements are recorded.
- [ ] Student completes missing requirements.
- [ ] School Bursar records fee payments.
- [ ] Director of Studies assigns academic information.
- [ ] Director of Discipline records attendance and discipline.
- [ ] Student is officially enrolled at College Foundation Sina Gerard.
